# Тесты блокнота и читалки

Запуск из `ws/reader3` (модели, сеть и `claude` не нужны):

    uv run --with pytest --with playwright==1.57.0 pytest

Playwright закреплён на 1.57.0: под эту версию уже скачан Chromium (`playwright install chromium` при необходимости).

| Файл | Что проверяет |
|---|---|
| `test_notebook_unit.py` | локации, парсинг цитат, проверка цитат (ok/moved/fuzzy/missing), подсветка, `extract_json`, DjVu-парсеры |
| `test_rag.py` | леммы RU/EN, чанки, лексический и гибридный поиск (поддельный эмбеддер), враждебные запросы, порядок реранкера |
| `test_api.py` | HTTP-API блокнота: доступ, подготовка книги, чат (SSE), цитаты, Студия, блокноты/заметки, `/internal/nb/*`, удаление книги |
| `test_agent.py` | `agent_stream` с поддельным `claude` (`fake_claude.py`): разбор потока, ошибки, таймаут, очистка временных файлов |
| `test_pdf_and_library.py` | PDF-слой, загрузка/удаление, маршруты страниц, чат по PDF, MCP-обёртки |
| `test_djvu.py` | DjVu с настоящими бинарниками DjVuLibre (пропускается, если их нет) |
| `test_ui.py` | браузер: структура, чат и цитаты, Студия (тест, карточки, карта, таблица), блокноты, телефон/планшет |
| `test_live.py` | опционально, `READER3_LIVE=1`: настоящий `claude` + MCP (тратит подписку) |

Фикстуры (`conftest.py`) строят временную библиотеку из трёх синтетических книг (RU PDF, EN PDF, RU EPUB).
